# Sujok AI

**Your Intelligent Sujok Therapy Assistant**

Sujok AI is a modern, professional, and mobile-responsive landing page built for Sujok Therapy practitioners, students, and teachers. It is designed with a premium healthcare and AI-inspired color scheme (blue, green, and white), featuring responsive layout structures, custom SVG iconography, interactive FAQ accordions, and click-to-chat WhatsApp integrations.

## 🌟 Features
*   **Fully Responsive Phone UI**: Structured grids, stackable cards, and sliding navigation drawers tailored for mobile viewports.
*   **Pricing Plans**: Display of premium Sujok AI assistant options:
    *   **Monthly Plan**: ₹1,000 INR / month.
    *   **Annual Plan**: ₹10,000 INR / year (Saves ₹2,000 INR - includes 2 months free).
*   **WhatsApp Integrations**: Floating WhatsApp widgets and direct link contact cards that trigger pre-filled support text messages.
*   **Interactive Accordion FAQ**: Compact answers explaining Sujok history, Six Ki energy constitutions, and correspondence systems.
*   **SEO Optimized**: Semantic HTML5 markup, meta descriptions, open-graph tags, and custom favicon.
